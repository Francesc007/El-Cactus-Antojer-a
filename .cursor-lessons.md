# Lecciones del proyecto

## React Compiler / set-state-in-effect
- No sincronizar estado derivado con `useEffect`.
- Cargar disponibilidad de reservas con `useCallback` + un efecto que depende de fecha y personas, no de copias intermedias.

## Inventario
- El stock nunca se edita a mano: siempre es suma de movimientos.
- Amarillo (atención) solo aplica con exactamente 1 unidad sobre el mínimo.

## Producción
- El navegador no escribe a tablas sensibles. Las mutaciones van por API/servidor.
- `SUPABASE_SERVICE_ROLE_KEY` solo en servidor.
- No registrar service worker de datos operativos en el primer deploy.

## TypeScript
- Un `if` sin paréntesis rompe `tsc` en `lib/errors.ts`. Siempre usar `if (cond) {`.

## Supabase / Postgres
- Las funciones nuevas reciben `EXECUTE` para `PUBLIC` por defecto. Después de crearlas hay que `REVOKE` a `public`/`anon` y dejar solo el rol que las usa (`authenticated` o `service_role`).
- Toda función SQL debe llevar `SET search_path = public, pg_temp` para cerrar el aviso “Function Search Path Mutable”.
- Las vistas deben crearse `with (security_invoker = true)` para no quedar como SECURITY DEFINER.

## Next.js
- No ejecutar `next build` mientras `next dev` usa la misma carpeta `.next`; corrompe chunks (`Cannot find module './331.js'`). Reinicia el dev server después de un build.
- El `fetch` parcheado de Next.js puede devolver `TypeError: fetch failed` al hablar con Supabase. El cliente de servidor debe usar `cache: 'no-store'`.
- Variables `NEXT_PUBLIC_*` en el shell pisan `.env.local`. Nunca dejar `example.supabase.co` exportado después de un build de CI.
- Si la página se ve sin estilos (iconos gigantes, imágenes estiradas), revisar que `/_next/static/css/app/layout.css` responda 200. Causa común: varios `npm run dev` y caché `.next` corrupta. Matar procesos en 3000/3001, borrar `.next` y levantar un solo servidor.
- En el cliente, `process.env[name]` dinámico siempre devuelve `undefined`. Las `NEXT_PUBLIC_*` deben leerse con acceso estático (`process.env.NEXT_PUBLIC_SUPABASE_URL`) o el login dirá “Supabase no está configurado” aunque `.env.local` esté bien.
